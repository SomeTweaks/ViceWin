ViceWin experimental runtime package

Requirements
- Windows 10/11 x64
- A Direct3D 12-capable GPU and current graphics driver
- A supported ScarlettX/GDK package containing MicrosoftGame.Config

Quick start
1. Run ViceWin.exe.
2. Browse to the game's executable inside its package directory.
3. Choose settings and press Launch.
4. Review vicewin.log if startup fails.

The launcher only accepts an executable belonging to a package with
MicrosoftGame.Config. It does not launch arbitrary Win32 games. The included
sample_package is a synthetic test package, not a commercial game.

This is an experimental compatibility runtime. No game files or proprietary
game content are included, and compatibility with any particular game is not
guaranteed.
